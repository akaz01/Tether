Tether 1.0.0

지정한 핫스팟이나 와이파이에 연결돼 있으면 노트북 뚜껑을 닫아도 작업이 계속되게 하는 무료 프로그램입니다.
연결돼 있지 않으면 평소처럼 뚜껑을 닫을 때 절전합니다.


[필요한 환경]
- Windows 10 또는 Windows 11 노트북
- 와이파이
- 설치 프로그램이나 관리자 권한은 필요 없습니다.


[시작하기]
1. ZIP 압축을 풀고 Tether.exe를 실행합니다.
2. "+ 네트워크 추가"를 눌러 핫스팟이나 와이파이를 고릅니다. 최대 3개까지 등록할 수 있습니다.
3. "활성화"를 누릅니다.

"활성화"를 누르면 Tether가 %LOCALAPPDATA%\Tether 폴더에 프로그램을 복사해서 뒤에서 동작합니다.
로그인할 때 자동으로 켜려면 "자동 시작"을 켜 주세요. 기본값은 꺼짐입니다.
와이파이가 끊기면 등록한 네트워크에 1순위부터 차례로 연결합니다.
사용 중인 연결은 기본으로 뺏지 않습니다. 설정에서 "상위 네트워크 전환"을 켜면 등록한 네트워크에 연결 중일 때 더 높은 순위로 옮깁니다.
더 높은 순위가 설정한 시간 동안 충분한 신호로 보여야 옮기고, 주변 검색 주기 때문에 1분쯤 더 걸릴 수 있습니다. 연결이 끊긴 직후나 전환 직후 5분 동안은 옮기지 않습니다.

목록에 네트워크가 없으면 Windows에서 그 네트워크에 먼저 한 번 연결해 주세요.
창을 닫아도 Tether는 뒤에서 계속 동작합니다. 시계 옆 아이콘에서 활성화와 비활성화를 바꿀 수 있습니다.


[보안 경고가 나올 때]
Tether는 코드 서명이 없는 무료 프로그램이라 경고가 나올 수 있습니다.
- Windows SmartScreen: "추가 정보"를 누른 뒤 "실행"을 누릅니다.
- 스마트 앱 컨트롤: 켜져 있으면 실행이 차단될 수 있습니다. 보안 기능을 끄는 것은 권하지 않습니다.
- 백신 프로그램: 자동 시작 등록을 막을 수 있습니다. 믿을 수 있는 곳에서 받은 파일이면 백신에서 Tether를 허용해 주세요.
- 회사 PC: 보안 정책이 있으면 IT 담당자에게 먼저 확인해 주세요.

받은 파일이 원본인지 확인하려면 배포처에 공개된 SHA-256 값과 비교해 주세요.


[꼭 알아 두세요]
- 무거운 작업 중에 뚜껑을 닫아 가방에 넣으면 많이 뜨거워질 수 있습니다. 가능하면 환기되는 곳에 두세요.
- 뚜껑을 닫은 뒤 연결이 끊기면 절전되지 않고 켜진 채로 있을 수 있습니다.
- Tether가 강제로 꺼지면 뚜껑 설정이 남을 수 있습니다. Tether를 다시 열면 복원됩니다.
- 휴대폰 핫스팟은 노트북이 켤 수 없습니다. 미리 켜 두고, 자동 꺼짐 기능을 꺼 주세요.
- Tether는 Windows의 뚜껑 닫기 동작과 화면 끄기 시간, 배터리 성능 설정을 바꿉니다.


[개인정보]
Tether는 인터넷으로 어떤 정보도 보내지 않습니다. 외부 서버에 접속하지 않고, 사용 통계도 모으지 않습니다.
계정 가입이나 이름, 메일 같은 개인정보를 요구하지 않습니다. 와이파이 비밀번호도 묻지 않고 Windows에 저장된 연결을 그대로 씁니다.
프로그램 안에 AI 기능은 없고, AI 서비스를 쓰지 않습니다.
설정과 기록은 이 컴퓨터의 %LOCALAPPDATA%\Tether 폴더에만 저장됩니다. 기록에는 연결한 네트워크 이름이 남습니다.


[제거]
Tether 창을 닫고 Tether.exe가 있는 폴더를 지우면 끝납니다.
30초쯤 뒤 뚜껑 닫기 동작이 절전으로 돌아가고, 자동 시작이 해제되며, 프로그램과 기록이 삭제되고, Tether가 꺼집니다.
등록한 네트워크와 설정은 %LOCALAPPDATA%\Tether 폴더에 남습니다. 백신이 파일을 격리해서 제거로 처리되어도, 다시 받아 실행하면 이어서 쓸 수 있습니다. 모두 지우려면 이 폴더도 지워 주세요.
화면 끄기 시간과 배터리 저발열은 그대로 남으니, 원래대로 쓰려면 제거 전에 설정에서 바꿔 주세요.

- 폴더를 옮길 때: 먼저 "비활성화"를 누르고 옮긴 뒤, 새 위치의 Tether.exe를 여세요. 활성화한 채 옮기면 제거로 처리되고, 비활성화했어도 새 위치에서 열기 전에 다시 활성화하거나 재부팅하면 제거로 처리됩니다.
- 비활성화한 채 폴더를 지운 경우: 자동 시작이 켜져 있으면 다음 로그인 때 정리됩니다.
- Tether가 꺼져 있을 때 폴더를 지운 경우: 정리할 프로그램이 돌고 있지 않습니다. %LOCALAPPDATA%\Tether 폴더도 직접 지워 주세요.
- USB나 네트워크 폴더에서 실행한 경우: 빠지거나 끊겨도 제거되지 않게 폴더 삭제를 감지하지 않습니다. 제거하려면 비활성화하고 자동 시작을 끈 뒤 재부팅하고, %LOCALAPPDATA%\Tether 폴더를 지워 주세요.


[면책]
이 프로그램은 있는 그대로 무료로 제공됩니다.
사용으로 생긴 발열, 배터리 소모, 작업 손실, 기기 손상 등에 대해 제작자는 책임지지 않습니다.
